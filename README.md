
🛒 E-Commerce Data Analysis Using Python

📌 Project Overview

This project focuses on analyzing an e-commerce sales dataset containing 1,000 order records. The objective is to understand sales performance, revenue trends, product performance, and city-wise sales using Python.

An interactive sales dashboard was also created using Plotly to present key business metrics and visualizations in one place.

🎯 Project Objectives

- Analyze overall sales and revenue.
- Identify the best-performing product categories.
- Understand monthly revenue trends.
- Analyze city-wise sales performance.
- Identify the top 5 best-selling products.
- Generate meaningful business insights.

📂 Dataset Description

The dataset contains 1,000 records and 8 columns:

- Order_ID
- Order_Date
- Product
- Category
- Price
- Quantity
- City
- Revenue
